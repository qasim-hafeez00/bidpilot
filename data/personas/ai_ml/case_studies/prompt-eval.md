# Prompt evaluation harness for an AI startup

## Context
Prompt changes kept silently breaking production behaviour. The client was a AI startup company.

## What I did
Regression suite of 300 cases with LLM and rule graders running in CI. I worked mainly with Python, Prompt Engineering, LLM. Under the hood the system relied on dataframe tooling, automated test-and-deploy pipelines.

## Outcome
The project caught 11 regressions before release in two months.

# Customer-support chatbot with ticket deflection

## Context
A Shopify store's support inbox was overwhelmed during sales. The client was a e-commerce company.

## What I did
Built an intent router plus an LLM answerer grounded on the help centre, with human hand-off. I worked mainly with Python, Chatbot, LLM, Prompt Engineering. Under the hood the system relied on an in-memory cache and message broker, a typed async Python web service.

## Outcome
The project deflected 38% of tickets in the first month.

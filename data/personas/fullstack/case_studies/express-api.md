# Inventory API for a warehouse

## Context
Stock counts drifted between warehouse and website. The client was a logistics company.

## What I did
Event-driven inventory API with nightly reconciliation. I worked mainly with Node.js, Express, MySQL, REST API. Under the hood the system relied on a reproducible container image.

## Outcome
The project stock discrepancies cut from 6% to 0.5%.

# Admin portal for a clinic network

## Context
Staff managed schedules in shared spreadsheets. The client was a healthcare company.

## What I did
Role-based admin portal with audit trail. I worked mainly with Vue.js, Flask, MySQL. Under the hood the system relied on a reproducible container image, secure sign-in.

## Outcome
The project scheduling errors dropped by 70%.

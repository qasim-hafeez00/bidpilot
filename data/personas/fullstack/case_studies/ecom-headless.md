# Headless e-commerce storefront

## Context
A fashion brand's theme store was slow on mobile. The client was a fashion retail company.

## What I did
Headless storefront on the Storefront API with static generation. I worked mainly with Next.js, React, Shopify, Tailwind CSS. Under the hood the system relied on a typed query layer.

## Outcome
The project Lighthouse mobile score from 41 to 93; conversion up 18%.
